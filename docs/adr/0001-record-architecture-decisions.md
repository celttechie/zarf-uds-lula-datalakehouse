# 1. Record Architecture Decisions

Date: 2026-08-13

## Status

Accepted

## Context

We need to record architectural and technical decisions made for the **Air-Gapped IL4/IL5 Accredited Data Lakehouse** project to ensure maintainability, clear decision history, and alignment with industry best practices.

## Decision

We will use Architecture Decision Records (ADRs) as described by Michael Nygard. Each ADR will be stored in `docs/adr/` as a Markdown document named `NNNN-short-title.md`.

## Consequences

* Architectural choices, trade-offs, and design rationale will be recorded explicitly.
* Future developers and interviewers will have transparent context on project decisions.
